## 🔧 System Design Methodology

### Design Questions (in order):

1. **What problem are we solving?** — Define clear success metrics
2. **What should be deterministic?** — Logic that always produces the same result
3. **Where does AI add value?** — Strategic AI placement, not everywhere
4. **What data is needed?** — Data architecture and pipelines
5. **What state must persist?** — Database and cache design
6. **What can fail?** — Failure mode analysis
7. **What actions need authorization?** — Security and approval gates
8. **How do we evaluate correctness?** — Testing and metrics
9. **How do we observe the system?** — Logging, metrics, traces
10. **How do we deploy and operate?** — Infrastructure and CI/CD

### Engineering Principles

| Principle | Description |
|-----------|-------------|
| **Models as Components** | LLMs are intelligent components, not the entire solution |
| **Deterministic First** | Use code for deterministic logic, AI for reasoning |
| **Measure Everything** | Data-driven decisions on performance and optimization |
| **Design for Failure** | Assume timeouts, API failures, incomplete data |
| **Automate with Boundaries** | Autonomy needs controls and human oversight |
