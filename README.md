# Engineering Principles

### 01 — Models are components

An LLM is rarely the complete solution.

The surrounding architecture determines reliability, security, latency, cost, and maintainability.

### 02 — Deterministic logic belongs in code

Use AI where reasoning and ambiguity matter.

Use conventional software where deterministic behavior is possible.

### 03 — Measure before optimizing

Performance decisions should be supported by:

* Metrics
* Benchmarks
* Logs
* Traces
* Evaluation datasets

### 04 — Failure is part of the design

Production systems should assume:

* Models fail
* APIs timeout
* Dependencies disappear
* Data is incomplete
* Tools return unexpected results
* Users behave unpredictably

### 05 — Automation needs boundaries

Autonomy should increase productivity without removing necessary controls.

# System Design Mindset

When designing an AI system, I think through:

```text
1. What problem are we solving?
2. What should be deterministic?
3. Where does AI add value?
4. What data does the system need?
5. What state must be persisted?
6. What can fail?
7. What actions require authorization?
8. How do we evaluate correctness?
9. How do we observe the system?
10. How do we deploy and operate it?
```
